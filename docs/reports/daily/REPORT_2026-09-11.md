## §3 작업 둘 — 백엔드에 「유령 변경」 64건이 쌓여 있었다

인계 문서는 백엔드가 **전부 커밋돼 있다**고 적었는데, 실제로는 64개 파일이 수정 상태로
떠 있었다. 둘 다 맞는 말이었다 — **글자는 하나도 안 바뀌었기 때문이다.**

**무엇이 문제였나 (역할 → 작용 → 결과)**

```
Windows 편집기가 파일을 저장하면서 줄바꿈 기호를 바꾼다
  → 글자가 같아도 도구는 «모든 줄이 바뀌었다»고 읽는다
  → 그대로 이력에 남으면, 누가 이 줄을 썼나 추적할 때
     실제 작업이 전부 «오늘 이 정리 작업»으로 덮여 안 보이게 된다
```

**글자 변경이 정말 0인지 64개 전수로 확인했다.**

| 잰 것 | 값 |
| --- | --- |
| 수정으로 뜬 파일 | 64개 |
| 겉보기 변경량 | 5,571줄 추가 · 5,571줄 삭제 (= 전 줄이 다시 쓰였다) |
| 줄바꿈 기호를 빼고 비교했을 때 다른 파일 | **64개 중 0개** |

**어떻게 풀었나** — 디스크를 이력에 남은 상태로 되돌리고, 앞으로 같은 일이 생겨도
**이력에는 들어가지 않도록** 규칙 한 줄을 넣었다. Windows 배치 파일만은 Windows 방식이라야
실행되므로, 그 예외가 새 규칙보다 뒤에 오게 순서를 맞췄다.

# (이어서) 학년을 고칠 길을 낸다

**한 줄 요약:** 학년이 없는 학생에게 서버가 「학년을 먼저 설정해 주세요」라고 답하면서도
**정작 설정할 자리가 없었다.** 그 막다른 길을 뚫었다 — 서버에 설정 경로를, 마이페이지에
고르는 자리를 만들었다.

## §7 용어 보태기

| 말 | 뜻 |
| --- | --- |
| **학년이 없는 계정** | 구글로 가입한 학생. 구글은 학년을 알려주지 않아 그 칸이 비어 있다. |
| **400 / 500** | 400 은 「보낸 쪽이 할 일이 남았다」, 500 은 「서버가 고장났다」. 둘은 다른 말이다. |
| **어휘의 정본** | 학년 같은 낱말 목록을 «한 곳에만» 적어 두고 나머지는 그것을 가져다 쓰는 것. |

## §8 무엇이 막다른 길이었나 (역할 → 작용 → 결과)

```
구글 가입은 학년을 받지 않는다
  → 학년을 쓰는 기능 다섯이 그 학생에게 「학년을 먼저 설정해 주세요」(400) 라고 답한다
  → 그런데 마이페이지는 학년을 «보여주기만» 했다
  → 학생은 무엇을 하라는지 듣고도 «할 수가 없다». 고리가 거기서 끊긴다
```

📌 어제 세션이 500 을 400 으로 바꾼 것은 옳았다. 다만 **그 400 을 풀 자리를 같이 열지
않아서**, 「서버가 고장난 것처럼 보이는 상태」가 「학생이 갇힌 상태」로 바뀌었을 뿐이었다.

## §12 이어서 배운 것

| | |
| --- | --- |
| **안내 문구는 «갈 곳»이 있을 때만 안내다** | 「마이페이지에서 고를 수 있어요」가 사실이 아니었다. 서버 응답을 고칠 때 **그 말이 가리키는 자리가 실제로 있는지** 같이 봐야 한다 |
| **사본이 셋이면 다음은 넷이다** | 학년 목록이 두 곳에 적혀 있었다. 새 화면을 그냥 만들었으면 조용히 넷이 됐을 것이고, 학년이 하나 늘 때 화면마다 다른 목록이 보였을 것이다 |
| **인계 문서의 명령이 그대로 돌지 않을 수 있다** | 빌드 명령의 경로 표기가 이 환경에서는 안 맞아 「Gradle 빌드가 없다」로 죽었다. 경로를 바꾸니 돌았다 → 부록 |

## 부록 (이어서) — 개발자용 추적 정보

**서버** `PATCH /api/users/me/grade`

- 신규: `domain/user/dto/request/UpdateGradeRequest.java` (`@NotNull Grade grade`)

**🔄 인계 문서 §6 의 빌드 명령 정정** — WSL 에서는 마운트 경로가 `/c/...` 가 아니라
`/mnt/c/...` 여야 한다. 원문대로 실행하면 빈 디렉터리가 붙어
`Directory '/app' does not contain a Gradle build` 로 죽는다. 이번에 쓴 명령:

```bash
docker run --rm \
  -v /mnt/c/intellij_workspace/ailang:/app \
  -v ailang-gradle-cache:/home/gradle/.gradle \
  -v ailang-build:/app/build \
  -v ailang-projcache:/app/.gradle \
  -w /app gradle:8.14-jdk21 \
  gradle compileJava test --tests '*AnswerNormalizerTest*' \
    --tests '*DifficultyFallbackTest*' --tests '*UserGradesTest*' \
    --tests '*UpdateGradeRequestTest*'
```

⚠️ 실행 중 `Could not read directory path '/app/src/...'` 가 한 번 났다 — Windows 바인드
마운트의 일시적 읽기 실패다. 같은 명령을 다시 돌리면 통과한다.
