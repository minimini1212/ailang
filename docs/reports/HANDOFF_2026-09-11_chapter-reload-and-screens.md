이번에 `UserGrades.requireName` 으로 모아, 학년이 없으면 **400 + 「마이페이지에서 학년을
고를 수 있어요」** 라고 답하게 했다. 화면도 그 말을 그대로 띄운다.

🔴 **그런데 마이페이지에 학년을 «고치는» 길이 없다.** 실측으로 확인했다:

```

user.api.ts       학년 수정 호출이 없다
UserController    PatchMapping 이 /me/assessment 하나뿐 — 학년 수정 API 가 없다
```

즉 **구글로 가입한 학생은 400 을 받고 갈 곳이 없다.** 종전에는 500 이었으니 나빠진 것은
아니지만, **고리가 거기서 끊긴다.** 백엔드 API + 화면 둘 다 필요하다.

### ② 정답이 200자를 넘는 문제 20건이 처음부터 조용히 빠지고 있었다

```
저장된 1,132건 — 정답 글자수 최대  190
빠진     20건 — 정답 글자수 최소  213      ← 정확히 갈린다
```

`PROBLEMS.ANSWER` 가 `VARCHAR2(200)` 인데 원본의 정답 칸에 **정답과 풀이가 함께** 들어 있는
건이 있다(최대 1,106바이트). 저장에서 터져 버려진다.
🔴 **예전 DB 도 1,132건이었다** — 이번에 생긴 것이 아니라 처음부터 그랬고 아무도 몰랐다.
⚠️ 빠지는 것이 대부분 **서술형·표가 있는 문제**라 자료가 치우친다.

⚠️ **대응은 사용자 결정이다** — 컬럼을 넓힐지(CLOB) · 정답만 잘라 담고 나머지를 해설로
보낼지 · 20건을 버릴지는 **채점 방식과 얽힌 판단**이다.
→ 근거: [`../research/reload-result-2026-09-10.md`](../research/reload-result-2026-09-10.md) §2

## §6 개발 환경 — 🔴 함정 둘

### ① 이 PC 에 JDK 21 이 없다

Docker 로 빌드한다. **`build` 와 `.gradle` 을 반드시 볼륨으로 뺀다** — Windows 바인드 마운트에
두면 Gradle 이 자기가 만든 디렉터리를 다시 못 읽어 죽는다.

```bash
docker run --rm \
  -v /c/intellij_workspace/ailang://app \
  -v ailang-gradle-cache://home/gradle/.gradle \
  -v ailang-build://app/build \
  -v ailang-projcache://app/.gradle \
  -w //app gradle:8.14-jdk21 \
  gradle compileJava test --tests '*AnswerNormalizerTest*' \
    --tests '*DifficultyFallbackTest*' --tests '*UserGradesTest*'
```

⚠️ **`--tests` 필터를 빼지 말 것** — 없으면 Oracle·Redis 가 필요한 검사까지 걸려 멈춘다.
📌 현재 인프라 없이 도는 검사 **23건** (정규화 15 · 난이도 폴백 4 · 학년 4).

### ② 🔴 Docker 안에서 앱을 «기동»하지 말 것

이번 세션에서 그렇게 했다가 **Docker Desktop 이 두 번 죽었다.** 기동에만 597초가 걸렸고,
WSL VM 과의 통신이 막혀(`Wsl/Service/0x8007274c`) `docker ps` 조차 안 됐다.
Oracle·Redis·Mongo 가 이미 떠 있는 위에 JVM 을 더 올린 것이 원인으로 보인다.

🎯 **앱은 IntelliJ 로 띄운다.** 빌드·검사만 Docker 로 한다.
⚠️ 그래도 막히면 Docker Desktop 재시작으로는 안 풀린다 — **`wsl --shutdown` 이 필요하다**
(그러면 `Ubuntu` 배포판도 같이 내려가므로 **사용자에게 먼저 물을 것**).

### 인프라

```bash
docker compose up -d        # Oracle · Redis · AI 서버
./gradlew bootRun           # 스프링은 compose 에 없다 — 따로 띄운다
```

`.env` 는 사용자가 직접 관리한다 — **Claude 가 쓰지 않는다**(레포 HARD RULE).
