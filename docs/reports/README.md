하나」**만 적는다. 결정 사항은 [`../rules/`](../rules/) 로, 남은 일은
[`../../TODOS.md`](../../TODOS.md) 로 각각 보내고 여기서는 링크만 한다.

## 🔴 리포트 작성 규율 (읽는 사람이 코드를 모른다)

[`../../CLAUDE.md`](../../CLAUDE.md) 의 「Report writing」과 같은 내용이다.

- **§0 용어표를 맨 위에 둔다.** 그 절만 읽고도 아래 숫자를 해석할 수 있어야 한다.
- **원인은 「역할 → 작용 → 결과」로 쓴다.**
  ✅ *"클라이언트가 채점 결과를 보낸다 → 서버가 그대로 저장한다 → 정답률이 조작된다"*
  ❌ *"`selfJudge` 처리 문제"*
- **제목·요약에 코드 식별자를 쓰지 않는다.** 개발자용 추적 정보는 부록으로.
- **비율은 분모와 함께.** ❌ *"적재 실패 12%"* → ✅ *"문제 1,340건 중 161건 적재 실패"*
