## §1. 무엇을, 왜

**초등 3학년 ~ 고등 1학년 학생**에게 자기 수준에 맞는 수학 문제를 내주고,
푼 직후에 그 문제와 연결된 개념을 **학년 눈높이로** 설명해 주는 학습 플랫폼.

### 이 제품이 파는 것

문제집은 이미 많다. 이 제품이 파는 것은 문제가 아니라 **「너에게 맞는 문제」** 다.

```
정답률  →  난이도  →  다음에 나올 문제  →  학생이 푼다  →  정답률
   ▲                                                        │
   └────────────────────────────────────────────────────────┘
```

🔴 **그래서 정답률의 신뢰성이 제품의 신뢰성이다.** 정답률이 조작 가능하면 「맞춤형」이
남아 있지 않다. 이것이 이 프로젝트에서 타협하지 않는 한 줄이고,
규율은 [`rules/grading-and-difficulty.md`](rules/grading-and-difficulty.md) 에 있다.

### 학원·문제집과 다른 점

- 학원 숙제는 **모두 같은 문제**를 푼다. 여기는 학생마다 다르다.
- 문제집 해설은 **그 문제의 풀이**를 준다. 여기는 **그 개념**을 학년 말로 설명한다.

### 대상

`ELEM_3` `ELEM_4` `ELEM_5` `ELEM_6` `MIDDLE_1` `MIDDLE_2` `MIDDLE_3` `HIGH_1`
(초3 ~ 고1, 8개 학년)

## §2. 기능 스코프

### ① 회원 — ✅ 있다

이메일 가입(인증코드 필수) · 구글 로그인 · JWT 쿠키 인증 · 학년 선택 ·
같은 이메일의 LOCAL↔GOOGLE 중복 가입 차단

⚠️ **구글 가입은 학년을 받지 않는다.** 학년 없는 유저가 실제로 생기고, 학년을 쓰는
기능들이 그 유저에게 실패한다. 학년을 언제 어떻게 받을지는 아직 안 정했다 (§7).

### ② 문제 풀이 — ✅ 있다 (신뢰성은 §7)

| 방식 | 설명 |
| --- | --- |
| **맞춤형** | 그 챕터의 내 정답률에 맞는 난이도의 기출문제 |
| **랜덤** | 난이도 무관, 그 챕터 안에서 |
| **학년별 랜덤** | 챕터를 안 고르고 바로 |
| **진단 테스트** | 20문제 (하 7 · 중 7 · 상 6, 섞어서) |

**난이도 조정**: 3문제 미만은 그대로 · 80% 이상 상향 · 50% 미만 하향 · 그 사이 유지.
🎯 「3문제 미만」은 「못한다」가 아니라 **「아직 모른다」**다.

**문제 유형**: 객관식(4지선다) · 단답형

⚠️ 단답형은 **학생이 스스로 채점**한다. 수학 단답형은 `2/4`·`1/2`·`0.5` 가 다 맞는 답이라
문자열 비교가 어려워서 내린 우회다. 🔴 **그 우회가 정답률까지 학생에게 넘겼다** — §7.

### ③ 개념 설명 — ✅ 있다

문제를 낸 뒤 「개념 설명 보기」를 누르면, **학년 + 단원명 + 문제 본문**을 Gemini 에
넘겨 그 학년 수준의 설명을 받는다. 풀이가 아니라 **개념**이다 — 정의, 왜 중요한지,
실생활 예시.

### ④ AI 챗봇 — 🟡 있으나 반쪽

수학 자유 질문. 대화 맥락을 1시간 유지한다.
🔴 **RAG 는 아직 없다.** 지금은 Gemini 에 그대로 묻는다 — 우리 자료를 근거로 답하지 않는다.

### ⑤ AI 모의문제 — ✅ 있다

기출이 부족한 자리를 메우려고 Gemini 가 문제를 만든다.
🔴 **기출과 절대 섞이지 않는다.** 검증 안 된 정답이 학생의 난이도를 정하게 되기 때문이다.
⚠️ **사람이 검수하는 절차가 없다.** 학생에게 「AI가 만든 문제」라고 알릴지도 안 정했다.

### ⑥ RAG — ⬜ 없다 (Phase 3)

AI Hub 수학 자료를 벡터로 만들어 두고, 질문이 오면 **학년으로 걸러 비슷한 자료를 찾아**
그 내용을 근거로 답하게 한다.

🔴 **지금 「구현돼 있다」고 오해할 만한 흔적이 셋 있는데 코드는 0줄이다**:
`supabase` 의존성, **필수로 선언된** Supabase 키 두 개, `rag_service.py` 의 `# TODO` 한 줄.

### ⑦ 관리자 — ⬜ 없다 (Phase 4)

챕터·문제 CRUD, AI 생성 문제 검수, RAG 자료 업로드.
🔴 **지금 인가 체계에 역할 규칙이 하나도 없다** — 로그인만 하면 다 통과한다.

## §7. 결정 대기 — 🔴 혼자 정하지 말 것

| 항목 | 무엇을 정해야 하나 |

| **단답형 채점 방식** | 자가채점 유지 / 서버 채점 + 이의제기 / 통계 분리 — 세 안의 대가는 [`rules/grading-and-difficulty.md`](rules/grading-and-difficulty.md) §4 |
