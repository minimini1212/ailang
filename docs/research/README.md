# docs/research — 조사 원자료

**성격:** 판단의 **재료**. 결론이 아니라 「그때 무엇을 봤나」를 남긴다.

## 여기 들어갈 것

| 종류 | 예 |
| --- | --- |
| 외부 자료 구조 조사 | AI Hub 수학 자료의 JSON 필드가 실제로 어떻게 생겼나 |
| 자료 품질 실측 | 정답 추출이 안 되는 건이 몇 건인가, 어떤 모양인가 |
| 외부 API 조사 | Gemini 할당량·응답 지연 실측, 벡터 저장소 후보 비교 |
| 라이선스·이용 조건 | AI Hub 자료를 벡터 저장소에 넣어도 되는 범위 — **본 날짜와 함께** |

## 규칙

- 🔴 **본 날짜를 반드시 적는다.** 이 폴더의 자료는 **시점 기록**이다. 외부 자료도 API 도
  바뀐다. 날짜를 떼면 근거가 아니라 소문이 된다.
- 🔴 **「봤다」와 「코드에서 유추했다」를 구분해 적는다.** 둘을 섞으면 검증된 사실처럼
  읽히고, 다음 사람이 확인 없이 그 위에 쌓는다.
- **결론을 여기 적지 않는다.** 결론과 판정은 [`../rules/`](../rules/) 로 간다. 여기는 재료만.
- **원문을 요약하지 말고 인용한다.** 특히 이용 조건은 요약하는 순간 다른 뜻이 된다.
- **나중에 고치지 않는다** — 그날 알던 것을 남기는 것이 이 폴더의 가치다.
  달라졌으면 새 파일을 쓰고 각주로 잇는다.

파일명: `<주제>-<YYYY-MM-DD>.md` 또는 성격이 고정된 것은 `<주제>.md`.
